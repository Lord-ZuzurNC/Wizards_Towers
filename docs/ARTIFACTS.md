# Artifacts — Wizards Towers

An Artifact is a world-unique rune bound to a floor of the Monolith, not to a wizard.
Hold the floor, use the rune in your spell.
Lose the floor and the rune leaves your spell.

## How to read this document

This catalogue holds exactly **100** Artifacts.
A world deals one Artifact to each of floors 1 to 48, so every world draws a different 48 out of the 100.
Floor 49 is the separate, special final floor described in `GLOSSARY.mine.md` — the payment window and overtime live there, and no Artifact is dealt to it.

Every Artifact has a **band** that says which floors may deal it.

| Band         | Floors | Role                                       |
| ------------ | ------ | ------------------------------------------ |
| **normal**   | 1-19   | Early-run power, found by any wizard.      |
| **enhanced** | 20-39  | Mid-run power, found by a wizard climbing. |
| **powerful** | 40-48  | Late-run power, found near the top.        |

**This pass's structural change, and the reason the tables below look different from the last catalogue.**
An Artifact used to be authored as a fixed pair: one effect, bolted to one hand-picked corruption.
Per the designer's design answer 26.3, that is wrong.
The effect and the corruption are **paired randomly when a world generates**, not authored together.
This document now has one table per attribute listing Artifacts with their **effect only**, and one shared **Corruptions** table that any Artifact can be paired with.
Because a corruption can land on any Artifact, no corruption may reference a specific Artifact's effect.
Every corruption in this document is a universal cost: a stat penalty, a resource drain, or a behavioural restriction that makes sense bolted onto anything.

**Every drain has a floor, binding rule.**
Any corruption that drains a stat or a resource states an explicit lower bound where it stops.
No corruption may reduce a wizard to zero or to something unplayable.

**Curing a corruption.**
A corruption is cured by the priest at the Monolith's Ground Floor for one life-stone.

Each Artifact table has four columns.

| Column           | Meaning                                                                         |
| ---------------- | ------------------------------------------------------------------------------- |
| **Name**         | World-unique, two to four words, never a bare glossary term.                    |
| **Band**         | Which floors may deal this Artifact: normal, enhanced, or powerful.             |
| **What it does** | The effect alone, in the terms this project already uses for stats and systems. |
| **Notes**        | Synergy, intended use, or a warning about the combination that breaks it.       |

The four groups below mirror the four rune attributes: Shape, Element, Duration, Effect.
An Artifact occupies the same slot an ordinary rune of that attribute would occupy, so an Artifact Effect still fills one of the two ordered Effect slots.
The quality bar is the same as last pass: each entry must do something an ordinary rune cannot, not a bigger number on something an ordinary rune already does.

## Corruptions

Corruptions are not authored onto an Artifact.
They are rolled at world generation and paired with whichever Artifact lands on a given floor, so the same corruption can appear on a Shape, an Element, a Duration or an Effect Artifact alike.
Every corruption below is written to make sense bolted onto anything, with no reference to any specific Artifact's effect.
A corruption is cured by the priest at the Monolith's Ground Floor for one life-stone.

⬜ **Severity grading, proposed.**
The table below sorts every corruption into **mild / harsh / severe**.
This grading does not exist in any generation code yet; it is a proposal for this pass.
The reason to adopt it: blind pairing is a real risk.
If a `powerful`-band Artifact can roll a `mild` corruption, a floor-48 wizard gets a strong effect for almost nothing, while a `normal`-band Artifact that rolls a `severe` corruption becomes a trap nobody should ever slot.
Weighting the roll — harsher corruptions biased toward more powerful Artifacts, milder ones toward weaker ones — keeps every Artifact a real decision instead of a lottery ticket that occasionally bricks a floor.

**Kept as instructed, re-scoped only where a rule forced it.**
`The Priest's Shortcut`, `Grave Standing` and `The Permanent Record` were explicitly praised and are kept.
`Grave Standing`'s old authored corruption cost nothing while the caster was alive, which was the main balance complaint against it.
Splitting corruption into its own randomly-paired table fixes that automatically: every world now rolls a real corruption for it, so slotting it is finally a decision rather than free insurance.
`Grave Standing` still needed one re-scope: it is explicitly written as an exception to Eternal's new "only acts while the wizard is near it" rule, since acting after the caster's own death is the entire point of the Artifact and an ordinary rune cannot do it.

## Notes for balancing

**Entries I think read as strong and worth watching first.**
`Last Stand on the Wall` and `Stonewarden's Mark` both convert a single good moment into a lasting advantage; paired with a mild corruption they could be the best floor-48 draw in the game.
`The Hoarded Stone` is the only way to manufacture a mana-stone at all, which makes its real value depend entirely on how rare mana-stones are meant to stay.
`Grave Standing` remains strong even after the corruption split, because its effect is pure insurance with no in-life downside; the corruption roll only taxes the slot, not the insurance itself.

**Entries I think read as weak as written.**
`The Peace-Keeper's Pity` deals no damage and gives away gold; it may need a secondary benefit to be worth a floor at all.
`Level's Grace` performs worse than an ordinary Effect against a same-level target, which is most targets most of the time; it may need its band lowered or its penalty window narrowed.
`The Priest's Shortcut` still depends on carrying a life-stone, and life-stones stay rare by design, so its uptime is low enough that it may remain a trap pick.

**Entries that depend on an undecided design question, marked where they appear above.**
⬜ `The Maze-Breaker` assumes mazes have a well-defined "solved state" a single hit can trigger, which `MAZES.md` has not committed to.
⬜ `The Permanent Record` assumes a dead wizard's run still banks something countable, open at `GLOSSARY.mine.md` 32.4.
⬜ `The Spirit's Second Throw` and `Spirit's Last Errand` both assume the spirit companion exists as described; `GLOSSARY.md` still marks the spirit system open at 10.7.
⬜ `Last Page Standing`, `The Grimoire Satellite` and `The Grimoire's Rest` all lean on the exact number of Grimoire positions a wizard holds, which `GLOSSARY.mine.md` marks open at 29.2.
⬜ The severity grading on the Corruptions table (mild / harsh / severe) is a proposal, not an implemented system; see the note above the Corruptions table for the reasoning.
⬜ Whether Floor 49's "window" and "overtime" mechanics referenced by `The Overtime Bell` and `The Final Window` behave exactly as `GLOSSARY.mine.md` describes is itself still marked open there at 29.0 and 29.3.

**A note on scope, honestly stated.**
This pass kept every old entry that still worked and invented 24 new ones to fill out Shape, Element and Duration.
It did not attempt to re-weigh every kept entry's power level against the others; that is the next pass's job, once a cost bar exists and a corruption roll can actually be tested against a real Artifact draw.
